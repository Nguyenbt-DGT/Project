Risk b

MVP2/MVP3 sequencing risk

§6, decision (b)

TOURING_PLAN (MVP2) is sequenced ahead of MAP_TRACKING (MVP3) only because the project owner named it "Module 2" — not because a dependency or value analysis supports that order. Every competitor researched couples route planning to ride-recording data, so a pure analysis would rank MAP_TRACKING first or pair the two. This sequencing choice needs explicit PO confirmation before MVP2 build starts, not just before MVP3.

Risk a

OQ-G1 auth conflict risk

§6, decision (a)

The shipped build uses email/password sign-in, but the documented business requirement is Gmail-only ( / ). The deciding factor is an App Store review implication: Apple Sign-In may be required if any third-party sign-in (Gmail) is offered. The single recommended resolution point is before MVP2 starts — the longer it ships unreconciled, the more UI/tests/docs accumulate against whichever path turns out wrong.
