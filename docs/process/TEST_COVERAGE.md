## Status values
- **Covered** — the rule's acceptance criteria (including edge cases) are asserted by a passing test.
- **Partially covered** — happy path only, or missing an edge case from the KB.
- **No test** — a release blocker per Rule 6.2 if the rule is in scope for the current milestone.
